# 🌍 InfoTravels

![Screenshot da Home](https://github.com/cayresbr/Slider/blob/develop/img/screenshot-home1.jpg?raw=true)

**InfoTravels** é um projeto web focado em apresentar destinos turísticos com informações úteis e um design visualmente atraente. A proposta é proporcionar uma experiência interativa e moderna para quem busca explorar o mundo.

🔗 Acesse o site: [https://infotravels.netlify.app](https://infotravels.netlify.app)
